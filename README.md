# LynxRaft

LynxRaft is a cloud-based platform for decentralized data management, featuring autonomous node management and real-time data processing capabilities.

LynxRaft is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/LynxRaft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

LynxRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
